## 🎯 Доступ к панели

### Способ 1: Через интерфейс

1. Войдите в аккаунт на платформе
2. Нажмите кнопку **"Admin"** в верхнем меню
3. Перейдите по адресу: `http://localhost:5173/admin-panel`

### Способ 2: Прямая ссылка

```
http://localhost:5173/admin-panel
```

## 🎭 Управление знаменитостями

### Добавление новой знаменитости

1. **Откройте вкладку "Знаменитости"**
2. **Нажмите кнопку "Добавить знаменитость"**
3. **Заполните форму:**
   - **Имя**: Полное имя знаменитости
   - **URL изображения**: Ссылка на фото (поддерживается автогенерация)
   - **Описание**: Краткая информация о персоне
   - **Категория**: Выберите подходящую (Актёр/Музыкант/и т.д.)
4. **Нажмите "Сохранить"**

### Автогенерация изображений

Для быстрого получения качественных изображений:

1. Введите имя знаменитости
2. Нажмите **"Автоматически сгенерировать URL"**
3. Система создаст оптимизированную ссылку Unsplash

### Редактирование существующих записей

1. **Найдите карточку знаменитости**
2. **Нажмите кнопку "Изменить"** (желтая)
3. **Внесите изменения в форме**
4. **Сохраните результат**

### Удаление записей

⚠️ **Внимание**: Удаление необратимо!

1. **Нажмите кнопку "Удалить"** (красная)
2. **Подтвердите действие** в диалоге

## 📰 Управление блогом

### Создание нового поста

1. **Откройте вкладку "Блог"**
2. **Нажмите "Создать пост"**
3. **Заполните все поля:**

#### Основная информация

- **Заголовок**: Привлекательный заголовок статьи
- **Краткое описание**: Превью для списка постов
- **Автор**: Имя автора статьи
- **Дата публикации**: Когда опубликовать (можно планировать)

#### Контент

- **Содержание**: Основной текст (поддерживает HTML)
- **Категория**: Тематическая группа
- **Изображение**: URL обложки статьи

### HTML в контенте

Блог поддерживает HTML-разметку для богатого форматирования:

```html
<h2>Заголовок раздела</h2>
<p>Обычный текст параграфа.</p>

<ul>
  <li><strong>Жирный текст</strong> - выделение</li>
  <li><em>Курсив</em> - акцент</li>
</ul>

<ol>
  <li>Нумерованный список</li>
  <li>Пошаговые инструкции</li>
</ol>
```

### Категории блога

Доступные категории:

- **Новости** - Актуальные события
- **Технологии** - AI и инновации
- **Обучение** - Гайды и туториалы
- **Обновления** - Изменения платформы
- **AI** - Искусственный интеллект

## 🔄 Синхронизация данных

### Автоматическое сохранение

Все изменения автоматически сохраняются:

- **Знаменитости**: В `localStorage` и JSON файл
- **Блог**: В `localStorage` браузера
- **Настройки**: В локальном хранилище

### Резервное копирование

Для безопасности данных:

1. Регулярно экспортируйте JSON файлы
2. Делайте скриншоты важных настроек
3. Ведите лог изменений

## 🎨 Рекомендации по изображениям

### Для знаменитостей

- **Размер**: 400x400px (квадратные)
- **Качество**: HD (высокое разрешение)
- **Формат**: JPEG/PNG
- **Фокус**: Четкое лицо, хорошее освещение

### Для блога

- **Размер**: 800x500px (соотношение 16:10)
- **Качество**: Оптимизированное для веб
- **Тематика**: Соответствует содержанию статьи

### Источники изображений

**Рекомендуемые платформы:**

- **Unsplash** - бесплатные HD фото
- **Pexels** - качественные стоковые изображения
- **Pixabay** - разнообразная библиотека

## 🚀 Производительность

### Оптимизация работы

Для лучшей производительности:

1. **Изображения**:

   - Используйте сжатые форматы
   - Добавляйте параметры оптимизации в URL
   - Пример: `?w=400&h=400&fit=crop&auto=format&q=80`

2. **Контент**:

   - Пишите содержательные, но лаконичные тексты
   - Используйте структурированную разметку
   - Добавляйте релевантные теги

3. **Навигация**:
   - Используйте поиск для быстрого доступа
   - Фильтруйте по категориям
   - Сортируйте по дате/алфавиту
