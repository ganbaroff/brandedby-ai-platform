# Быстрая инструкция: деплой на Vercel

Это удобный и быстрый способ публиковать ваш проект без ручной работы с API-токенами Cloudflare.

Шаги (коротко):

1. Зарегистрируйтесь / войдите на https://vercel.com и подключите ваш GitHub-аккаунт.
2. Нажмите «New Project» → Import Git Repository → выберите `ganbaroff/brandedby-ai-platform`.
3. При импорте укажите параметры сборки:
   - Build Command: `npm run build`
   - Output Directory: `dist/client`
   - Framework Preset: `Vite` (если доступно)
4. (Опционально) В разделе Environment Variables добавьте переменные окружения, которые использует приложение (например, `VITE_API_BASE_URL` и т.п.).
5. Нажмите «Deploy». Vercel автоматически создаст превью для PR и продакшн для `main`.

Подсказки и примечания:

- Preview Deploys: при каждом PR Vercel создаёт превью URL — удобно для быстрых проверок.
- Если сборка у вас выводит артефакты в другую папку, укажите её вместо `dist/client`.
- Vercel не исполняет Cloudflare Workers — это статический SPA-хостинг с поддержкой серверных функций (Serverless), но для вашего клиентского SPA это подходит.
- Если у вас есть кастомный домен, добавьте его в Vercel Dashboard → Domains и следуйте инструкции по DNS.
